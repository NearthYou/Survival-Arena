## 한계

- 자동 그래픽 검증은 Microsoft Basic Render Driver WARP였다. RTX 3050 Ti hardware 수치는 이 비교에 섞지 않았다.
- Windows 성능 evidence와 Linux sanitizer evidence의 commit이 다르다. 차이는 명시적 정수 변환과 aggregate 완전 초기화뿐이며 gameplay 로직은 바꾸지 않았다.
- working set은 처음보다 마지막 값이 컸지만 모든 표본에서 연속 증가하지 않았으므로 현재 guard는 통과했다. 장기 서비스 누수를 부정하는 증거로 확대 해석하지 않는다.
- 사전 full-state run과 실패한 interest-full run은 runner 문제를 재현한 자료이며 공식 네 mode 표에는 포함하지 않았다.
