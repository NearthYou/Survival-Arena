# 제목

## 상황

이 작업을 시작한 시점의 코드와 눈에 보인 문제를 적는다.

## 재현

실행 명령, 입력, 장면 seed, 하드웨어와 빌드 구성을 적는다.

## 관찰

로그, 프로파일, 프레임 캡처에서 확인한 사실만 적는다.

## 가설과 대안

원인 가설과 비교한 대안을 적고, 각 대안을 제외하거나 선택한 이유를 남긴다.

## 구현

바뀐 경계와 데이터 흐름을 설명한다. 핵심 코드 링크는 기준 commit SHA에 고정한다.

## 검증

변경 전후 결과와 원본 증거 경로를 적는다.
