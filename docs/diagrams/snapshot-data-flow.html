연결 책임

  1. authoritative-match → replicator: 권위 tick이 네트워크 world snapshot을 만든다.
  2. replicator → codec: 수신자 interest와 ack baseline으로 payload를 만든다.
  3. codec → udp-fragments: payload를 인코딩하고 크기에 맞춰 fragment로 나눈다.
  4. udp-fragments → reassembler: UDP datagram이 순서와 CRC 정보를 포함해 전달된다.
  5. reassembler → snapshot-stream: 완성된 payload를 검증하고 keyframe 또는 delta로 디코딩한다.
  6. snapshot-stream → predictor: 권위 위치와 ack 입력으로 로컬 예측을 보정한다.
  7. snapshot-stream → interpolator: 적용된 스냅샷을 원격 actor 보간 버퍼에 넣는다.
