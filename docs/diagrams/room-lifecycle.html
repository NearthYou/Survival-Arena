연결 책임

  1. waiting → waiting: create가 호스트를 포함한 Waiting 방을 만든다.
  2. waiting → waiting: join이 Waiting 방에만 플레이어를 추가한다.
  3. waiting → waiting: ready가 Waiting 멤버의 준비 상태를 갱신한다.
  4. waiting → starting: start가 호스트와 전원 준비를 검증한 뒤 예약을 시작한다.
  5. starting → in-match: worker ready가 endpoint를 확정하고 InMatch로 전이한다.
  6. starting → waiting: disconnect가 예약을 취소하고 Waiting으로 되돌린다.
