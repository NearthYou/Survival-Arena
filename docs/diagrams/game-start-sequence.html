텍스트 설명

구성 요소

  • Host host
  • Lobby lobby
  • Worker Registry worker-registry
  • Game Server game-server
  • Game Client game-client

호출 순서

  1. 1. host → lobby: 호스트가 준비 완료된 방의 시작을 요청한다.
  2. 2. lobby → worker-registry: 로비가 참가자 티켓과 함께 매치 예약을 요청한다.
  3. 3. worker-registry → game-server: 레지스트리가 선택한 유휴 워커에 예약을 전달한다.
  4. 4. game-server → worker-registry: 게임 서버가 권위 매치를 만들고 예약 준비를 알린다.
  5. 5. worker-registry → lobby: 레지스트리가 워커 endpoint를 예약 완료 이벤트로 돌려준다.
  6. 6. lobby → host: 로비가 매치 티켓과 TCP 및 UDP endpoint를 발급한다.
  7. 7. host → game-client: 호스트 흐름이 발급 정보를 게임 세션에 넘긴다.
  8. 8. game-client → game-server: 게임 클라이언트가 티켓으로 TCP 인증을 요청한다.
  9. 9. game-server → game-client: 게임 서버가 actor와 tick rate를 포함한 welcome을 보낸다.
  10. 10. game-client → game-server: 게임 클라이언트가 UDP token으로 datagram 경로를 bind한다.
  11. 11. game-server → game-client: 인증 참가자가 준비되면 권위 매치와 스냅샷 전송이 시작된다.
