연결 책임

  1. client → engine: 입력과 렌더링 루프를 엔진에 위임한다.
  2. client → lobby-client: 호스트 흐름이 로비 요청을 시작한다.
  3. lobby-client → lobby-server: 로비 메시지를 TCP로 교환한다.
  4. lobby-client → protocol: 공유 메시지 형식으로 요청을 인코딩한다.
  5. lobby-server → worker-control: 매치 예약을 유휴 워커에 배정한다.
  6. lobby-server → protocol: 방과 워커 상태를 프로토콜 타입으로 노출한다.
  7. worker-control → game-server: 예약과 취소를 게임 서버에 전달한다.
  8. game-server → protocol: 게임 세션과 UDP 스냅샷을 직렬화한다.
  9. game-server → simulation: 게임 서버가 protocol input을 권위 tick의 simulation state로 연결한다.
